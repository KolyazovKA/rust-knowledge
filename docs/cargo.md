# Cargo

Cargo - является системой сборки и менеджером пакетов для ЯП Rust. С помощью него можно делать сборку кода, загрузку библиотек и создание библиотке.

## Команды

```sh
# Просмотр версии cargo
cargo --version
```

```sh
# Создание нового проекта
cargo new project_name
```

```sh
# Сборка с помощью cargo
cargo build
# - Выполняется в корне проекта
# - Кладет файл в папку target/debug
```

```sh
# Запуск проекта с помощью cargo
cargo run
# - Выполняется в корне проекта
```

```sh
# Проверка кода перед компиляцией
cargo check
```

```sh
# Сборка релизной версии
cargo build --release
# - Производит больше оптимизаций для испольняемого файла
# - Кладет файл в папку target/release
# - Занимает значительно больше времени чем простой cargo build
```
