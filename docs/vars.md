# Переменные в rust

## Объявление переменные

Для создания переменной используется ключевое слово `let`
Например:

```rust
let num = 5;
```

По умолчанию все переменные в rust являются неизменяемыми. Поэтому для того чтобы переменная не была обычной константой используется ключевое слово `mut`
Например:

```rust
let mut count = 0;
```

## Вывод переменных в строках

Использовать переменные для вывода через `println!` можно - для этого достачно обернуть их в `{}` либо передав как аргумент
Например:

```rust
// Вариант 1
println!("Count={count}");
// Вариант 2
println!("Count={}", count + num);
```

## Кoнстанты

Константы - значения, которые привязаны к имени и не могут быть изменены. Отличают константы от перменных тем, что константы нельзя сделать изменяемыми с помощью mut, а также тем, что они могут быть заданы только константым выражением, а не результатом вычисленного значения в runtime-е - только во время компиляции (например `const THREE_HOURS_IN_SECONDS: u32 = 60 * 60 * 3;`).
Константы живут все время работы программы там где они были объявлены.
